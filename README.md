# 🍕 Pizza Sales Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing pizza sales data using SQL to understand sales performance, customer ordering patterns, and product popularity.

The analysis uses a relational dataset containing orders, order details, pizza information, and pizza categories. SQL queries are used to extract meaningful insights from the data.

**Tools Used:** MySQL, MySQL Workbench  
**Project Type:** SQL Data Analysis

## 🎯 Project Objectives

- Calculate the total number of orders placed.
- Analyze total revenue generated from pizza sales.
- Identify the highest-priced pizza.
- Find the most commonly ordered pizza size.
- Identify the top 5 most ordered pizza types.
- Calculate the total quantity ordered for each pizza category.
- Analyze order distribution by hour.
- Examine the distribution of pizza types by category.
- Calculate the average number of pizzas ordered per day.
- Identify the top 3 pizza types based on revenue.
- Calculate category-wise revenue contribution.

## 📂 Dataset

The project uses four CSV files:

1. `orders.csv` – Order dates, times, and order IDs.
2. `order_details.csv` – Order details, pizza IDs, and quantities.
3. `pizzas.csv` – Pizza sizes, prices, and pizza IDs.
4. `pizza_types.csv` – Pizza names, categories, and pizza type IDs.

## 🧮 SQL Concepts Used

- SELECT and WHERE
- Aggregate functions: SUM(), COUNT(), AVG()
- GROUP BY and ORDER BY
- INNER JOIN
- Subqueries
- DISTINCT
- LIMIT
- Date and time functions
- Revenue calculations

## 📊 Analysis and Business Insights

The SQL queries explore:
- Overall order volume and revenue.
- Popular pizza sizes and pizza types.
- Category-wise pizza demand.
- Hourly ordering patterns.
- Average daily pizza sales.
- Revenue contribution across pizza categories.
